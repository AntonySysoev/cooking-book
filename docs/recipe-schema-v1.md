# Cooking Book: формат рецептов v1

Рецепты хранятся в отдельных YAML-файлах в `recipes/`. Категории определены централизованно в `data/categories.yaml`. Интерфейс и общие функции сайта (масштабирование, отметка ингредиентов и шагов, печать, удержание экрана включённым) относятся к коду сайта, а не к данным конкретного рецепта.

## Обязательные поля

- `id`: постоянный уникальный идентификатор в формате slug.
- `title`: название.
- `category`: ID категории из `data/categories.yaml`.
- `yield`: выход рецепта с количеством или диапазоном и единицей.
- `ingredients`: список канонических ингредиентов.
- `steps`: список шагов приготовления.

## Необязательные поля

`description`, `subcategory`, `tags`, `time`, `equipment`, `ingredient_groups`, `tips`, `storage`.

Время указывается только в целых минутах. Для диапазонов используются пары `*_minutes_min` и `*_minutes_max`. На странице время от 60 минут показывается в часах и минутах с правильными русскими формами.

## Ингредиенты, количества и масштабирование

Точные количества задаются через `quantity`; диапазоны — через `quantity_min` и `quantity_max`. Если количество неизвестно или намеренно не указано, поле `quantity` не добавляется и не заменяется на `null`. При заданном количестве обязательно указывается `unit`.

Масштабирование вычисляется от исходных количеств. При коэффициенте 1 показывается исходная величина; при другом коэффициенте — только пересчитанная величина, округлённая до 0,1 с удалением лишних нулей. Количества в шагах ссылаются на ингредиенты, поэтому масштабируются вместе с ними. Температуры, время, размеры форм и параметры процесса не масштабируются.

Если один ингредиент используется в нескольких местах, он описывается один раз и получает `parts` для распределения по этапам:

```yaml
- id: butter
  name: Сливочное масло
  quantity: 155
  unit: г
  parts:
    - id: dough
      name: В тесто
      quantity: 75
      group: dough
    - id: filling
      name: В начинку
      quantity: 80
      group: filling
```

Обычные части должны в сумме совпадать с общим количеством. Для компонентов, которые получаются из одной исходной единицы и не суммируются (например, 4 яйца дают 4 желтка и 4 белка), используется `parts_mode: components`.

Ссылка на ингредиент в шаге:

```yaml
ingredients:
  - ingredient: butter
    part: dough
```

Необязательные ингредиенты отмечаются `optional: true`. Для дробных количеств используется десятичная точка. Масса предпочтительнее объёмных единиц, когда ингредиент можно надёжно взвесить.

## Проверка

Установи зависимости и запусти валидатор из корня репозитория:

```bash
python -m pip install -r requirements.txt
python scripts/validate_recipes.py
```

Валидатор проверяет обязательные поля, уникальность ID, ссылки на ингредиенты и части, категории, единицы, диапазоны количества и времени, а также суммы обычных частей.
